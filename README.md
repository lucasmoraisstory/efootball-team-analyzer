# Analisador de Desempenho de Elenco - eFootball Simulator ⚽

Script desenvolvido em Python que simula um sistema de análise estatística para equipes de eSports ou games de futebol digital. O programa captura dados de entrada do usuário, processa métricas técnicas e gera um relatório detalhado de performance do elenco.

###  Tecnologias Utilizadas
- Python 3
- Estruturas de Dados Dinâmicas (Dicionários e Listas por Compreensão)
- Tratamento de Exceções (`try/except`) para validação de entradas

###  Funcionalidades
- Entrada dinâmica de dados com validação de notas técnicas.
- Cálculo aritmético automatizado da média de desempenho do time.
- Filtro lógico inteligente para identificação do destaque do elenco e de jogadores com performance abaixo da média.
